KeySprint 打字竞赛 - Windows 局域网部署说明（免 Docker）
=========================================================

一、这是什么
  这个压缩包是完整的 KeySprint 服务端：学生用浏览器访问你电脑上的服务，
  电脑本身不需要联网、不需要安装 Docker、不需要云服务器，也不需要域名。
  外网不能用（比如 GitHub）完全不影响使用。

二、首次部署（约 5 分钟）
  1. 把压缩包解压到固定目录，例如 D:\KeySprint
     （zip 是扁平的：只解压一次就能看到 keysprint.exe 等文件，没有多余目录层级；
      不要在压缩包里直接双击运行，web 目录缺失会启动失败）
  2. 双击 allow-firewall.bat，选择“以管理员身份运行”，放行 8080 端口
  3. 双击 start.bat 启动服务；这个黑色窗口保持打开就是服务在运行
     - 首次运行会自动生成 config.env（含随机 JWT_SECRET）和 data 目录
  4. 老师本机浏览器打开 http://127.0.0.1:8080
     - 第一次进入是初始化页面，创建管理员账号
  5. 查本机局域网地址：按 Win+R 输入 cmd，运行 ipconfig，记下“IPv4 地址”
     - 例如 192.168.1.23，学生访问 http://192.168.1.23:8080
     - 建议让学校把教师机 IP 固定（静态 IP 或 DHCP 保留），避免地址变化
  6. 学生电脑用浏览器（Chrome / Edge）打开上面的地址，输入老师给的比赛编号即可
  7. 建议重启后自动启动：双击 install-autostart.bat（管理员），
     之后开机即自动运行，无需登录 Windows 桌面

三、日常使用
  - 开始上课：确认服务在运行（打开 http://127.0.0.1:8080 能进后台即可）
  - 停止服务：双击 stop.bat，或直接关闭启动窗口
  - 后台“系统配置”里可以改网站标题、副标题；内网不需要备案号，留空即可
  - 多个老师要用：管理员在“教师管理”里新建账号，各自的班级/竞赛/成绩互不可见
  - 教师机上建议关闭自动睡眠/休眠，否则服务会中断

四、备份与升级
  - 备份：先停止服务，然后复制整个 data 目录（里面有 keysprint.db）
  - 升级：停止服务，用新版本解压覆盖 keysprint.exe 和 web 目录，
    保留 data 与 config.env，再启动即可（数据库会自动升级结构）

五、常见问题
  - 学生打不开：检查教师机 IP 是否变化、防火墙是否放行 8080、
    两台机器是否在同一网段；教师机网络位置建议设为“专用网络”
  - 端口被占用：修改 config.env 的 ADDR=:8081，并同步 allow-firewall.bat 里的 PORT
  - 页面能打开但比赛连不上：通常是防火墙拦截了 8080 的 TCP，
    重新用管理员身份运行 allow-firewall.bat
  - 服务起不来：查看 logs\keysprint.log 的最后几行
  - 杀毒软件拦截：把整个目录加入白名单
  - 开机自启没生效：运行 install-autostart.bat（管理员）后，
    在“任务计划程序”里查看 KeySprint 任务是否已启用

六、文件说明
  keysprint.exe            服务主程序（纯静态，无需 .NET/VC++ 运行库）
  web\                    前端页面
  data\                   数据库目录（首次启动生成，请勿删除）
  logs\                   运行日志（自动创建）
  config.env               配置（首次启动自动生成）
  config.env.example       配置说明示例
  start.bat                启动服务
  stop.bat                 停止服务
  allow-firewall.bat       放行防火墙端口（管理员）
  install-autostart.bat    注册开机自启（管理员）
  remove-autostart.bat     取消开机自启（管理员）
  VERSION.txt              版本与构建信息
